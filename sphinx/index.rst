SMS++
=====

SMS++ is a set of C++ classes intended to provide a system for modeling
complex, block-structured mathematical models, and solving them via
sophisticated, structure-exploiting algorithms. This site gathers the
README, the general description and the API reference of the core library
and of all its modules; the same reference is also on the
`Doxygen site <https://smspp.gitlab.io/smspp-project/>`_, and the
`User Manual <https://smspp.gitlab.io/smspp-project/manual/>`_ describes
the use of SMS++ from the beginning.
