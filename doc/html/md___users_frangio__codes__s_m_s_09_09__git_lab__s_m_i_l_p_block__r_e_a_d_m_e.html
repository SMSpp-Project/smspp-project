S[imple/tructured]MILPBlock

This is a very small project aimed at providing a very simple example of a SMS++ :Block that only has the "abstract implementation" in terms of FRowConstraint and FRealObjective whose underlying Function is Linear; basically, a (MI)LP. Besides these, OneVarConstraint(s) are also allowed to more efficiently handle bound (sign) constraints.

However, in order to cater for the inherent composability of Block, two different classes are implemented:

  • SimpleMILPBlock is a "leaf" MILP block, i.e., it has a single set of ColVariable x, a single linear objective function in these, a single set of linear constraints in these, and no "inner" Block.
  • StructuredMILPBlock derives from SimpleMILPBlock and therefore shares all its features; however, it may have any number of "inner" Block, which may be either SimpleMILPBlock or StructuredMILPBlock (so that a tree-shaped MILP with any degree of nesting can be represented). Hence, a StructuredMILPBlock also has a set of "linking" constraints in its x variables and in the x variables of its inner S[imple/tructured]MILPBlock.

The project obviously requires the "core" SMS++, avalable at 

https://gitlab.com/frangio68/sms_plus_plus

The arrangement of folders is assumed to be 

some root folder
 |
 +- SMS++ (the "core" SMS++)
 |
 +- SMILPBlock (this project)

SMILPBlock/test contains a simple test main that reads MILP problems from files in a custom test-based format and serialize/deserialize them in/from NetCDF files.
