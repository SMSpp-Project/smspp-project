Detailed Description

Implementation of several "classic" Shortest Path Tree algorithms to solve uncapacitated single-source Min Cost Flow problems. The actual algorithm can be chosen at compile time by setting a proper switch. Conforms to the standard MCF interface defined in MCFClass.h.
