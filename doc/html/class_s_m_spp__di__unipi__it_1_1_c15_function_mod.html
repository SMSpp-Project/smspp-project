constructor: takes the type of Modification and a C15Function pointer

constructor: takes the type of the Modification and a pointer to the affected C15Function. Note that while the enum c15function_mod_type is provided to encode the possible values of modification, the field f_type is of type "int", and therefore so is the parameter of the constructor, in order to allow derived classes to "extend" the set of possible types of modifications.
