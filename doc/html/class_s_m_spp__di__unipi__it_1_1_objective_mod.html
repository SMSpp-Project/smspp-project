Cconstructor: takes a pointer to the affected Objective and the type of the Modification. Note that while the enum of_mod_type is provided to encode the possible values of modification, the field f_type is of type "int", and therefore so is the parameter of the constructor, in order to allow derived classes to "extend" the set of possible types of changes.
