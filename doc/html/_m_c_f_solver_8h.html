Detailed Description

Header file for the MCFSolver class, implementing the Solver interface, in particular in its CDASolver version, for Min-Cost Flow problems as set by MCFBlock.

This is only a relatively thin wrapper class around solvers under the MCFClass interface. To avoid a pointer to an internal object, the class is template over the underlying :MCFClass object, which implies that most of the code is in the header file.
