Detailed Description

Header file for the abstract Solver class, which represent the basic interface between a Block [see Block.h], representing (possibly together with its recursively nested sub-Blocks) a (block-structured mathematical) model, and any algorithm capable of "solving" it, i.e., (hopefully) producing feasible solutions, either "good" or provably (approximately) optimal ones, or proving that there is none. Since doing this has to be expected to costly, the class implements the ThinComputeInterface paradigm.
