typedef unsigned int ModParam

public type for parameters controlling issuing of Modification

Public type for parameters controlling how Modification are issued. It is defined "at global scope" so that all methods of all relevant classes can use a consistent interface.

enum amododification_type

public enum for ways of issuing a Modification

Public enum for describing if and how any method potentially issuing an AModification should actually issue it. The enum is defined "at global scope" so that all methods of all relevant classes can use a consistent interface.
