Detailed Description

A few versions of operator>> for loading pairs, lists and arrays. For lists and arrays the format is always

number of elements k for i = 1 to k

  • element of the list

while for pairs the format is just

first element of the pair second element of the pair

It is assumed that each element can be read with >> itself, which rules out pointers. Elements are separated by whitespaces and comments (see eatcomments above).
