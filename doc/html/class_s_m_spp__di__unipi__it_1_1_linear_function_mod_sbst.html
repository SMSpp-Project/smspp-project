Detailed Description

derived from C05FunctionModVarsSbst for changes in subset of coefficients

Derived class from C05FunctionModVarsSbst to describe changes specific to a LinearFunction, i.e., those of a subset of coefficients.

The change of some of the coefficients in a linear function perfectly coincides with what the type of modification of C05FunctionModVarsSbst "SomeEntriesChange" postulates. Indeed, there is no real reason for defining this class, as it is identical to C05FunctionModVarsSbst, save for the fact that some Block / Solver may want to be sure that the Modification is actually coming out of a LinearFunction.
