Detailed Description

Header file for the concrete class StructuredMILPBlock, which implements the Block concept [see Block.h] for a simple-ish problem having only a fixed number of linear constraints on a fixed number of variables, everything only represented in "abstract form", but can have any number of sub-Block of the same type, with some constraints (possibly) being the "linking" ones.
