The SMS++ Project

"Umbrella" project that just unifies many different projects related to the SMS++ structured modeling system as sub-projects.

Current sub-projects:

  • the "core" SMS++
  • S[imple/tructured]MILPBlock
  • MCFBlock / MCFSolver

Also, some sub-projects require further projects

  • the MCFClass project for MCFSolver

The main benefit of this umbrella project is a unified Doxygen documentation that can be produced by running doxygen into doxygen/.
