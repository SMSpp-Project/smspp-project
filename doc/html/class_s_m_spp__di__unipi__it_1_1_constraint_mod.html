Detailed Description

class to describe modifications specific to a Constraint

Derived class from AModification to describe modifications to a Constraint, i.e., relaxing and enforcing it.

constructor: takes the type of Modification and a Constraint pointer

Constructor: takes the type of the Modification and a pointer to the affected Constraint. Note that while the enum cons_mod_type is provided to encode the possible values of modification, the field f_type is of type "int", and therefore so is the parameter of the constructor, in order to allow derived classes to "extend" the set of possible types of modifications.
