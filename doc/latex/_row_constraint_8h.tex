\subsection{Detailed Description}
Header file for the {\itshape abstract} Row\+Constraint class, derived from Constraint, which is intended as the base class for all the Constraints that are have a \char`\"{}row form\char`\"{}, that is

L\+HS $<$= ( some function from Variables to reals ) $<$= R\+HS

where L\+HS and R\+HS are two extended reals (hopefully at least one of which is finite and L\+HS $<$= R\+HS, but this is not enforced in the class).
