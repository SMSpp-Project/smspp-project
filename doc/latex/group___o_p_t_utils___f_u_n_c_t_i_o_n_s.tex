If, for any reason, the read operation fails, then the parameter is given the default value \textquotesingle{}Dflt\textquotesingle{}. Otherwise, all the rest of the line up to the nearest newline (\textquotesingle{}~\newline
\textquotesingle{}) carachter is flushed.
