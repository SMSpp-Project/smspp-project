\subsection{Detailed Description}
Header file for the One\+Var\+Constraint class, derived from Row\+Constraint, which is a class that defines a Row\+Constraint where the row contains a {\itshape single} Col\+Variable; hence, \begin{DoxyVerb}       some function from Variables to reals
\end{DoxyVerb}


can basically only be the (real) value of that single Col\+Variable, and the Constraint itself can basically only constrain that value to live into some (possibly, degenerate) real interval.

From One\+Var\+Constraint a few classes are derived that deal with different versions of the interval\+:


\begin{DoxyItemize}
\item Box\+Constraint has user-\/defined L\+HS and R\+HS;
\item L\+B\+Constraint has user-\/defined L\+HS and R\+HS = +\+Infty (Lower Bound);
\item U\+B\+Constraint has L\+HS = -\/\+Infty and user-\/defined R\+HS (Upper Bound);
\item N\+N\+Constraint has L\+HS = 0 and R\+HS = +\+Infty (Non-\/\+Negativity);
\item N\+P\+Constraint has L\+HS = -\/\+Infty and R\+HS = 0 (Non-\/\+Positivity);
\item Z\+O\+Constraint has L\+HS = 0 and R\+HS = 1 (Zero-\/\+One).
\end{DoxyItemize}

Besides saving a bit of space, the classes with fixed L\+HS and/or R\+HS guarantee that it can never be changed, which might be useful.
