\subsection{Detailed Description}
a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_row_constraint}{Row\+Constraint}} with a single \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} 

The class \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_one_var_constraint}{One\+Var\+Constraint}}, derived from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_row_constraint}{Row\+Constraint}}, defines a row constraint where the row contains a single \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}}; hence, \begin{DoxyVerb}       some function from Variables to reals
\end{DoxyVerb}


can basically only be the value of that single \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}}, and the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_constraint}{Constraint}} itself can basically only constrain that value to live into some (possibly, degenerate) interval. Yet, \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_one_var_constraint}{One\+Var\+Constraint}} still does not specify how the interval is managed (like \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_row_constraint}{Row\+Constraint}}) to leave freedom to further derived classes to do this in different ways.

It would, of course, be possible to have a constraint of the form

L\+HS $<$= f( x ) $<$= R\+HS

where f(x) is a univariate function (x is a single \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}}). However, for algebraic functions this should often be equivalently stated as the constraint that x belongs to some set of intervals, i.\+e., as a bunch of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_one_var_constraint}{One\+Var\+Constraint}}. Support for the fact that f( x ) can live in a set of different intervals may be added to \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_row_constraint}{Row\+Constraint}} (and hence to \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_one_var_constraint}{One\+Var\+Constraint}} one day), but that day is not today.
