\subsection{Detailed Description}
The \mbox{\hyperlink{class_s_p_tree}{S\+P\+Tree}} class derives from the abstract base class \mbox{\hyperlink{class_m_c_f_class}{M\+C\+F\+Class}}, thus sharing its (standard) interface, and implements Shortest Path Tree algorithms for solving \char`\"{}uncapacitated\char`\"{} (Linear) Min Cost Flow problems with one source node.

\begin{DoxyWarning}{Warning}
The S\+PT algorithm will enter in an infinite loop if a directed cycle of negative cost exists in the graph\+: there is no check about this in the code. 
\end{DoxyWarning}
