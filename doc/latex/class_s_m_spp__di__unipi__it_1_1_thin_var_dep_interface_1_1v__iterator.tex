\subsection{Detailed Description}
virtualized standard iterator 

\mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_var_dep_interface_1_1v__iterator}{Thin\+Var\+Dep\+Interface\+::v\+\_\+iterator}}, the {\itshape definition} of an iterator with (almost) the right traits to allow sifting through the \char`\"{}active\char`\"{} \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}}.

Unless ordinary iterators, the class is abstract, which means that classes derived from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_var_dep_interface}{Thin\+Var\+Dep\+Interface}} will have to actually implement this for their own version of the set of \char`\"{}active\char`\"{} \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}}. This is why, rather than the two standard versions of operator++ (prefix and postfix) returning an iterator (which cannot be done, since the class is abstract) there is only one version doing the increment. This single version is then transformed into the ordinary two by the \char`\"{}normal\char`\"{} iterator.
