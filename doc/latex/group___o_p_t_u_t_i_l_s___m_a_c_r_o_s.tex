The class O\+P\+Trand is defined below to give an abstract interface to the different random generators that are used in different platforms. This is needed since random generators are one of the less standard parts of the C\mbox{[}++\mbox{]} library. The value of the O\+P\+T\+\_\+\+R\+A\+N\+D\+OM constant selects among the different timing routines\+:


\begin{DoxyItemize}
\item 0 = an hand-\/made implementation of a rather good random number generator is used; note that this assumes that long ints $>$= 32 bits
\item 1 = standard rand() / srand() pair, common to all C libreries but not very sophisticated
\item 2 = drand48() / srand48(), common on Unix architectures and pretty good.
\end{DoxyItemize}
