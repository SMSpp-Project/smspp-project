\subsection{Detailed Description}
Header file for the Constraint class, a quite general base class of all the possible type of constraints that a Block can support. Very few assumptions are made about what form the constraint actually has, this being demanded to derived classes. Since Constraint can be costly to compute (think multiple integrals for probability constraints or min-\/max functions requiring the solution of a hard optimization problem), the class implements the Thin\+Compute\+Interface paradigm. Also, since a Constraint depends on a set of \char`\"{}active\char`\"{} Variable, it implements the Thin\+Var\+Dep\+Interface paradigm.
