\subsection{Detailed Description}
an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} that is a function between \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} and the reals 

The class \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_real_objective}{Real\+Objective}} quickly specializes the more general \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} to the case where the objective function is a function between \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} (of any possinle type) and the reals. More specifically, a type \char`\"{}\+O\+F\+Value\char`\"{} is defined, which is bound by default to doubles, to hold the type of the objective function return value. Changing this type here is possible but it changes it to the whole S\+M\+S++ hierarchy, so this does not look too reasonable; if one really needs a different return value than double can rather re-\/define a similar class to this.

returns the (real) value of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} 

Pure virtual method that returns the (real) value of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} given the values of the Variables it depends onto. More specifically, the method has to return the value that the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} {\itshape had} at the last time in which \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective_a504d4e3e174c7a518cc66156a8a45ce5}{compute()}} has been called. It is an error to call this method if \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective_a504d4e3e174c7a518cc66156a8a45ce5}{compute()}} has never been called, although implementations are allowed not to check this and return any random response\+: is the users\textquotesingle{} responsibility to ensure that \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective_a504d4e3e174c7a518cc66156a8a45ce5}{compute()}} has been called at the proper time.
