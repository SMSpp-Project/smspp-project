\subsection{Detailed Description}
class to describe changes of a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} involving \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} 

Derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod}{Function\+Mod}} to describe changes of a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} that involve the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} \char`\"{}active\char`\"{} in it. The basic changes are the addition and removal of Variables from a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. This class is \char`\"{}abstract\char`\"{} in that it does not specify {\itshape which} \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} are affected; for the case of removals this could be taken to mean \char`\"{}all\char`\"{} (but this does not work for addition). However, the idea is that the two derived classes \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod_vars_rngd}{Function\+Mod\+Vars\+Rngd}} and \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod_vars_sbst}{Function\+Mod\+Vars\+Sbst}} are then defined to specify the affected \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} in two different ways, and \char`\"{}remove all Variable\char`\"{} is easily implemented in the former.

When \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} are added to or removed from a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}, the \char`\"{}quasi-\/additivity\char`\"{} property (see definition below) may or may not be satisfied. When it is satisfied, the value of shift is finite. If this property is not satisfied, then the value of shift is infinity.

The quasi-\/additivity property is defined as follows.

Suppose that new Variables are added to the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. Let f\+\_\+old be the function before the modification and x be the vector of variables before the modification. Let y be the vector of variables that were added and f be the function after the modification. We say that the variables y are quasi-\/additively added to the function if and only if f(x, y) = f\+\_\+old(x) + shift for all x and for y = 0.

Suppose that Variables are removed from the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. Let f\+\_\+old be the function before the modification and z = (x,y) be the vector of variables before the modification. Let y be the vector of variables that were removed and f be the function after the modification. We say that the variables y are quasi-\/additively removed from the function if and only if f(x) = f\+\_\+old(x, y) + shift for all x and for y = 0.
