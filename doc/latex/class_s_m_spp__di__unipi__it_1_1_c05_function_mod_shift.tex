\subsection{Detailed Description}
class to describe modifications specific to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c05_function}{C05\+Function}} 

Derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod_vars}{Function\+Mod\+Vars}} to describe a change to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c05_function}{C05\+Function}} where some entries of the linearization are modified by a simple shift.

A case where this happens is the Lagrangian one, where each linearization is attached to one solution u\+\_\+i  U, and {\itshape some} of the R\+HS of the complicating constraints A u = b change, whereas all the rest of (P) remains the same. If b\textquotesingle{} is the new R\+HS vector, then all the previous linearizations g\+\_\+i = b -\/ A u\+\_\+i now have to become g\textquotesingle{}\+\_\+i = b\textquotesingle{} -\/ A u\+\_\+i; in other words, g\textquotesingle{}\+\_\+i = g\+\_\+i + ( b\textquotesingle{} -\/ b ). This allows to update all the linearizations that were stored in the global pool, without even having to ask the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} object about them (since the vector b\textquotesingle{} -\/ b is all the information that is needed), thereby re-\/using all the corresponding information to warm-\/start whatever algorithm one is using. This \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} basically provides (the equivalent of) b\textquotesingle{} -\/ b, in a sparse format.

get the vector of shifts 

Returns the vector with the components of the linearization vector (g) that were shifted and the respective amount. For each pair $<$ V$\ast$ , s $>$ in this shift vector, the pointer to the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} indicates the affected component of the linearization and the second element of the pair is the amount the value of that component has been shifted. So, if the value of the component associated with the variable V is g in some linearization, then the value of that component should become g + s.
