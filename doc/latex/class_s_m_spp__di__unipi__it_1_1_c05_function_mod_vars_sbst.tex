\subsection{Detailed Description}
class to describe changes to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c05_function}{C05\+Function}} involving a subset of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} 

Derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod_vars_sbst}{Function\+Mod\+Vars\+Sbst}} to describe changes specific to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c05_function}{C05\+Function}}. This class is (almost) completely analogous to \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c05_function_mod_vars_rngd}{C05\+Function\+Mod\+Vars\+Rngd}}, up to defining the identical type of modification

However, the set of indices of the linearization vectors affected by the change are now provided by the v\+\_\+vars std\+::vector of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} $\ast$. These can be, if needed, (hopefully, efficiently) translated into indices of the linearization vector by means of \mbox{\hyperlink{group___thin_var_dep_interface___c_l_a_s_s_e_s_ga88e11e9f684f5ac81df04df1cf14a423}{Thin\+Var\+Dep\+Interface\+::map\+\_\+active()}}.
