\subsection{Detailed Description}
Header file for the {\itshape abstract} Solver class, which represent the basic interface between a Block \mbox{[}see \mbox{\hyperlink{_block_8h}{Block.\+h}}\mbox{]}, representing (possibly together with its recursively nested sub-\/\+Blocks) a (block-\/structured mathematical) model, and any algorithm capable of \char`\"{}solving\char`\"{} it, i.\+e., (hopefully) producing feasible solutions, either \char`\"{}good\char`\"{} or provably (approximately) optimal ones, or proving that there is none. Since doing this has to be expected to costly, the class implements the Thin\+Compute\+Interface paradigm.
