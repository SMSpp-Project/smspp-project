{\footnotesize\ttfamily void UpdateT (\begin{DoxyParamCaption}\item[{A $\ast$}]{h,  }\item[{A $\ast$}]{k,  }\item[{N $\ast$}]{h1,  }\item[{N $\ast$}]{h2,  }\item[{N $\ast$}]{k1,  }\item[{N $\ast$}]{k2 }\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [private]}}

Method to update the spanning tree T every iteration. The spanning tree T is implemented with a bidirectional list stored in the node structure, which represents the nodes\textquotesingle{} order after a Post-\/\+Visit. The parameter of the method are the outgoing arc \char`\"{}h\char`\"{}, the incoming arc \char`\"{}k\char`\"{}, and the four nodes on the extremity of these arcs (for example h2 is the deepest node of the outgoing arc). Removing the arc \char`\"{}h\char`\"{} splits T in two subtrees\+: T1 (which contains the root of T) and T2, which will be re-\/connected by the incoming arc \char`\"{}k\char`\"{}. T2 will be reordered; in fact, the node \char`\"{}k2\char`\"{} becomes the root of T2 instead of \char`\"{}h2\char`\"{} and the hierarchy of T2 will be overturned. Then T2 will be moved; the root of T2 is changed, therefore the predecessor of the root will become the node \char`\"{}k1\char`\"{}.

This method uses the methods cut\+And\+Update\+Subtree() and paste\+Subtree(). First it cuts the node \char`\"{}k2\char`\"{} and its subtree from T using cut\+And\+Update\+Subtree(). Moreover the method cut\+And\+Update\+Subtree() updates the field \char`\"{}sub\+Tree\+Level\char`\"{} of every subtree\textquotesingle{}s nodes, since k2\textquotesingle{}s subtree will be moved from the bottom to the top of T2. Then the method paste\+Subtree() puts this subtree in the bidirectional list after the node \char`\"{}k1\char`\"{}. The same operations will be applied to the old precedessor of \char`\"{}k2\char`\"{} (which will become one of the childs of \char`\"{}k2\char`\"{}). This second subtree will be cut, the sub\+Tree\+Level fields will be updated, and it will be inserted in the bidirectional list after the k2\textquotesingle{}s subtree. This is iterated until the node \char`\"{}h2\char`\"{} is reached.
