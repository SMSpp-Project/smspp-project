The \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_m_c_f_solver}{M\+C\+F\+Solver}} implements the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} interface for Min-\/\+Cost Flow problems described by a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_m_c_f_block}{M\+C\+F\+Block}}. Because the linear M\+CF problem is a Linear Program it has a(n exact) dual, and therefore \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_m_c_f_solver}{M\+C\+F\+Solver}} implements the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_c_d_a_solver}{C\+D\+A\+Solver}} interface for also giving out dual information.

This is only a relatively thin wrapper class around solvers under the \mbox{\hyperlink{class_m_c_f_class}{M\+C\+F\+Class}} interface. To avoid a pointer to an internal object, the class is template over the underlying \+:\mbox{\hyperlink{class_m_c_f_class}{M\+C\+F\+Class}} object, which implies that most of the code is in the header file.
