\subsection{Detailed Description}
class to describe modifications that are specific to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} 

Derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_a_modification}{A\+Modification}} to describe modifications to a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. This is the base class for all Modifications related to Functions.

It is important to notice that a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod}{Function\+Mod}} contain sufficient information regarding the modification that was made on the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. This means that the information provided by a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function_mod}{Function\+Mod}} can be safely used to update previous knowledge about the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}.

This base class defines the simplest type of modification, which is associated to the value of the function. This modification can represent a constant shift in the value of the function. A function is said to be shifted by a constant if there is a finite scalar shift so that if the value of the function at a given point before the modification was f\+\_\+v, then the function value at that point after the modification is f\+\_\+v + shift.

In the worst case, the function may have been modified in such a way that everything that was known about the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} before the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} may no longer be valid. In particular, function values computed before the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} may now have changed in an unpredictable way. Therefore, function values that were computed before the modification must be recomputed if they are required to represent function values of the current (post \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}}) \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}}. This case is indicated by having the value of shift equals Inf$<$\+Function\+Value$>$().

A fundamental assumption is that any particular type of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} that is not recognized by a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} can be ignored by the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}}. For example, consider a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} that says that linearizations of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_function}{Function}} have changed. If the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} does not rely on linearizations, then the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} can safely ignore this \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}}.
