concrete class for \char`\"{}a group of logically related Modification\char`\"{} 

The class \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}} derives from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_a_modification}{A\+Modification}} and provides a S\+TL container of shared pointers to \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}} which can be used to implement in a simple way the concept of \char`\"{}a set of Modification logically
related to each other\char`\"{}. Note that since \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}} is a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_modification}{Modification}}, there is nothing preventing some of the sub-\/\+Modification of a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}} to be \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}} themselves, allowing to have arbitrarily nested \char`\"{}logically related Modification\char`\"{}. Indeed, \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}} also has a \char`\"{}father\char`\"{} pointer that simplifies traversals of the tree of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_group_modification}{Group\+Modification}}. Note that this is a raw pointer rather than a smart pointer, as it is not supposed to be used for anything else than traversing the data structure.
