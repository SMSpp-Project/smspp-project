\subsection{Detailed Description}

\item a pointer to a std\+::vector of pointers to objects of some type (...);
\item a pointer to a boost\+::multi\+\_\+array$<$\+K$>$ of objects of some type (...);
\item a pointer to a boost\+::multi\+\_\+array$<$\+K$>$ of pointers to objects of some type (...);
\item a pointer to a single std\+::list of objects of some type (...);
\item a pointer to a single std\+::list of pointers to objects of some type (...);
\item a pointer to a std\+::vector of std\+::list of objects of some type (...);
\item a pointer to a std\+::vector of std\+::list of pointers to objects of some type (...);
\item a pointer to a boost\+::multi\+\_\+array$<$\+K$>$ of std\+::list of objects of some type (...);
\item a pointer to a boost\+::multi\+\_\+array$<$\+K$>$ of std\+::list of pointers to objects of some type (...).
