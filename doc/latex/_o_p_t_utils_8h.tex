Small classes are provided for\+:
\begin{DoxyItemize}
\item timing of a code;
\item generating random numbers;
\item extracting \char`\"{}infinity\char`\"{} and \char`\"{}machine epsilon\char`\"{} of numeric types.
\end{DoxyItemize}

The classes can be adapted to different environments (if needed) by setting a compile-\/time switch in this file.
