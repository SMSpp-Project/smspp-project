\subsection{Detailed Description}
base class of all possible objective functions that a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}} can support 

The class \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} is the base class of all the possible type of objective that the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}} can support. This base class only supports a few fundamental facts\+:


\begin{DoxyItemize}
\item an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} belong to one \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}};
\item an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} is influenced by a set of \char`\"{}active\char`\"{} Variables, i.\+e., these which contribute to it setting its vaule\+: hence, the class implements the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_var_dep_interface}{Thin\+Var\+Dep\+Interface}} paradigm (i.\+e., derives from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_var_dep_interface}{Thin\+Var\+Dep\+Interface}}) that class makes no provisions about how this set is stored in order to leave more freedom to derived classes to implement it in specialized ways;
\item an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} has a \char`\"{}sense\char`\"{}, say, it can either be minimized or maximized;
\item an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} has to be computed, and this can be costly (think multiple integrals for expectation estimates or min-\/max functions requiring the solution of a hard optimization problem), which is why the class implements the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_compute_interface}{Thin\+Compute\+Interface}} paradigm (i.\+e., derives from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_compute_interface}{Thin\+Compute\+Interface}}).
\end{DoxyItemize}

Note that obviously an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} has a value, which might expected to be a single real value. However, this is not defined in this base class (e.\+g., in order to support multi-\/objective problems); therefore, the methods for reading it must be demanded to derived classes.

A fundamental design decision in S\+M\+S++ is that T\+HE \char`\"{}\+N\+A\+M\+E\char`\"{} OF AN \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} IS I\+TS M\+E\+M\+O\+RY A\+D\+D\+R\+E\+SS. This means that M\+O\+V\+I\+NG AN \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} IS N\+OT P\+O\+S\+S\+I\+B\+LE\+: copying an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} to a different memory location makes a distinct \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}}.

compute (evaluate) the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} 

Pure virtual method\+: it has to compute whatever expression/function the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} depends onto and store the results into some protected field. Evaluating an \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} can be a lengthy task, involving e.\+g. expensive function computations or numerical integrals, which is why \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}} are not computed by default, and need to be computed explicitly with this method. This is also why this implements the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective_a504d4e3e174c7a518cc66156a8a45ce5}{compute()}} method of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_compute_interface}{Thin\+Compute\+Interface}}; see the comments on the base class, in particular about the rules concerning what can change during a call to this method, and between two calls depending on the value of the changedvars parameter.

Note, however, that this method does not return the {\itshape value} of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_objective}{Objective}}, because the base class makes no provisions about what type this actually is.
