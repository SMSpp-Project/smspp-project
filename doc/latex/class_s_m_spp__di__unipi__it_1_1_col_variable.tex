\subsection{Detailed Description}
a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} that holds a single real value, possibly restricted to a subset 

The \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}} class, derived from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}}, is intended as the base class for all the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} that are single real values, possibly restricted to some subset (e.\+g., the integers). In a linear program this would correspond to a column in the coefficient matrix, whence the name.

This class extends \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_variable}{Variable}} to support the following further facts\+:


\begin{DoxyItemize}
\item A \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}} has a value, which is a real number. More specifically, a type \char`\"{}\+Var\+Value\char`\"{} is defined, which is bound by default to doubles, to hold the type of the variable. Changing this type here is possible, but this changes it to the whole S\+M\+S++ hierarchy, so this does not look too reasonable; if one really needs a different return value than double can rather re-\/define a similar class to this.
\item Other than being fiked, a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}} can be restricted to live into some \char`\"{}interesting\char`\"{} subsets of the reals, such as integers and binary values.
\end{DoxyItemize}

A trivial implementation of the set of \char`\"{}active stuff\char`\"{} for this \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_col_variable}{Col\+Variable}} as an ordered set of pointers to \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_thin_var_dep_interface}{Thin\+Var\+Dep\+Interface}}.
