template class for simple configurations (one single value) 

The \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_simple_configuration}{Simple\+Configuration}} class provides a simple implementation for a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_configuration}{Configuration}} object that boils down to one single value of some type. The type of the value is generic, but it is somehow assumed it is a basic type in that it must have a working assignment operator and $<$$<$ operator and be automatically destructible (hence, no pointer).

Important note\+: the class is template, hence infinitely many classes.
