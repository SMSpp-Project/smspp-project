Second-\/level de-\/serialization method\+: takes an open net\+C\+DF file and the index of a \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_configuration}{Configuration}} into the file, and returns the correspinding complete \+:\mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_configuration}{Configuration}} object.

There are three types of S\+M\+S++ net\+C\+DF files, corresponding to three values of the enum smspp\+\_\+net\+C\+D\+F\+\_\+file\+\_\+type \mbox{[}see \mbox{\hyperlink{_s_m_s_typedefs_8h}{S\+M\+S\+Typedefs.\+h}}\mbox{]}. Each file, when opened in a net\+C\+D\+F\+::\+Nc\+File (which is also a net\+C\+D\+F\+::\+Nc\+Group), must have an int net\+C\+DF attribute \char`\"{}\+S\+M\+S++\+\_\+file\+\_\+type\char`\"{} with one of the three values of the enum. The structure of the corresponding files is\+:


\begin{DoxyItemize}
\item e\+Prob\+File\+: the file (which is also a group) has any number of child groups with names \char`\"{}\+Prob\+\_\+0\char`\"{}, \char`\"{}\+Prob\+\_\+1\char`\"{}, ...
