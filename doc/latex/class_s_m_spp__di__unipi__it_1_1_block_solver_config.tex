\subsection{Detailed Description}
derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_configuration}{Configuration}} for configuring the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}} 

Derived class from \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_configuration}{Configuration}} to configure in one all the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} of a given \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}}, comprised those of the sub-\/\+Block (recursively), each with all its algorithmic parameters.

It contains three fields\+:
\begin{DoxyItemize}
\item a vector of strings containing the names of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} to be attached to the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}};
\item a vector of Compute\+Config$\ast$ for these same \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}}
\item a vector of \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block_solver_config}{Block\+Solver\+Config}} for each of the sub-\/\+Block of this \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block}{Block}}.
\end{DoxyItemize}

It also contains a bool field f\+\_\+diff which, if true, tells that the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block_solver_config}{Block\+Solver\+Config}} has to be \char`\"{}interpreted in a differential sense\char`\"{}\+: this means that all \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} whose name is not specified (empty string) must be left in their current state, all nullptr \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_compute_config}{Compute\+Config}} correspond to not changing the configuration of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}}, and all nullptr \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_block_solver_config}{Block\+Solver\+Config}} correspond to not changing any of the configurations of any of the \mbox{\hyperlink{class_s_m_spp__di__unipi__it_1_1_solver}{Solver}} attached to the corresponding sub-\/\+Block.
